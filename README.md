## About The Project

**GeoBot** is my upcoming Science Fair project made to make cave exploration safer and more affordable.

The project is aimed for amateur Scientists in exploring caves that are difficult and potentially dangerous for humans to access.


### Key Objectives

- **Environmental Monitoring:** Use sensors to see air quality and detect if the cave is unsafe for a human to get inside.
- **Visual Research:** Use a Live Feed of The Camera For Moving inside The Cave.
- **Sample Collection:** Use a robotic arm to collect Rock samples for Outside Research.
- **Terrain Navigation:** Utilize a Rocker-Bogie system to navigate cave terrain.
- **Remote Communication:** Create wireless and wired communication between GeoBot and a computer.

## Planned Hardware

GeoBot is designed around two main computing systems:

| Component | Purpose |
|---|---|
| Raspberry Pi Zero 2 W | Main processing & communication |
| Arduino Uno | Hardware control |
| Rocker-Bogie System | Move in Uneven terrain |
| N20 12V 200RPM Motors ×6 | Movement |
| L298 Motor Drivers ×2 | Motor control |
| IMX219 8MP Camera | Visual exploration |
| MQ-135 Sensor | air-quality monitoring |
| MG996R / MG90S Servos | Robotic arm movement |

GeoBot is currently under development. So there is no finalized software package available yet.

### Prerequisites

The planned project will require:

- A Raspberry Pi Zero 2 W.
- An Arduino Uno.
- Compatible motors, motor drivers and servos.
- A Raspberry Pi camera module.
- Different sensors.
- A computer for monitoring and control.
